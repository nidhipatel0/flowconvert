# FlowConvert UI - User Guide

## 🎯 Quick Start

### 1. Initial Upload
When you first visit FlowConvert, you'll see the upload zone:
- **Drag & drop** files directly onto the area
- **Click** anywhere to browse from your computer
- Supported formats: Images (JPG, PNG, WebP, GIF), PDFs, Documents (DOCX, TXT)
- Maximum file size: 50MB per file

### 2. Choose Your Tool Category
After uploading, click on one of the ribbon tabs:
- **Images** - Edit images (crop, resize, convert, compress)
- **PDF** - Work with PDF files (convert, organize, protect)
- **OCR** - Make documents searchable (scanning, edge detection)
- **PDF Editor** - Annotate and sign PDFs

### 3. Select Your Function
Under each tab, you'll see functions organized into groups:

#### Images Tab Groups:
| Group | What it does |
|-------|-------------|
| **Crop** | Cut parts of your image with aspect ratios |
| **Convert** | Change image format (JPG, PNG, WebP, PDF) |
| **Dimension** | Resize image to specific width/height |

#### PDF Tab Groups:
| Group | What it does |
|-------|-------------|
| **Convert** | Change PDF to Word, Excel, or PowerPoint |
| **Organize** | Split, extract, or merge PDF pages |
| **Enhance** | Compress size or organize pages |
| **Security** | Protect PDF with password |

#### OCR Tab Groups:
| Group | What it does |
|-------|-------------|
| **Scanning** | Make scanned text searchable |
| **Enhancement** | Improve document clarity and filters |

#### PDF Editor Tab Groups:
| Group | What it does |
|-------|-------------|
| **Edit** | Crop or annotate PDFs |
| **Sign** | Add electronic signatures |
| **Enhance** | Add watermarks and page numbers |
| **Personalize** | Translate or customize document |

## 📁 Managing Your Files

### File Sidebar
On the right side of your workspace, you'll see a compact file card showing:
- 📊 Total number of files
- 🖼️/📄 File icons (image or document)
- 📝 File name, format, and size
- ✏️ Delete button (appears on hover)

### Add More Files
1. Click **+ Add More Files** button in the workspace header
2. Upload additional files to your session
3. All files appear in the file sidebar

### Remove a File
1. Hover over the file card in the sidebar
2. Click the **X** button that appears
3. File is removed from your session

### View More Files
If you have more than 3 files:
1. Click **+N more files** at the bottom of the sidebar
2. All files are now visible
3. Click **Show Less** to collapse the list

## 🎯 Common Workflows

### Resize an Image
1. Upload your image → click **Images** tab
2. Click **Dimension** group → click **Resize**
3. Enter width/height or choose a preset ratio
4. Click **Apply** → Download

### Convert PDF to Word
1. Upload your PDF → click **PDF** tab
2. Click **Convert** group → click **To Word**
3. Preview the result → Click **Download**

### Make a Scanned PDF Searchable
1. Upload your PDF → click **OCR** tab
2. Click **Scanning** group → click **OCR Scan**
3. Select quality settings → Click **Process**
4. Download your searchable PDF

### Merge Multiple PDFs
1. Upload multiple PDFs → click **PDF** tab
2. Click **Organize** group → click **Merge**
3. Arrange pages in desired order
4. Click **Merge** → Download

### Add Watermark to PDF
1. Upload your PDF → click **PDF Editor** tab
2. Click **Enhance** group → click **Watermark**
3. Enter watermark text and position
4. Click **Apply** → Download

## 🔒 Privacy & Security

### Client-Side Processing
✅ **Your files stay on your computer**
- All image and PDF processing happens locally in your browser
- No files are uploaded to our servers for basic operations
- Your privacy is our priority

### Server-Side Processing
🔐 When needed (for complex conversions):
- Files are encrypted with AES-256 encryption
- Processed on secure servers
- Automatically deleted within 5 minutes
- Never stored or shared

## 🆘 Getting Help

### Help Center
Click **? Help** in the top right for:
- Frequently asked questions
- Feature tutorials
- Troubleshooting guide
- Contact support

### Common Issues

**Q: My file is too large**
A: Maximum file size is 50MB. Compress first or upgrade to Premium.

**Q: Where are my files?**
A: All files are stored locally in your browser. They're cleared when you close the tab.

**Q: Can I use FlowConvert offline?**
A: Basic image operations work offline. PDF conversion requires internet.

**Q: How do I save my settings?**
A: Settings are saved automatically to your browser.

**Q: Can I use FlowConvert on my phone?**
A: Yes! FlowConvert is fully responsive and works on mobile browsers.

## 💡 Best Practices

### For Images
- Use PNG for lossless quality
- Use JPG for smaller file sizes
- Use WebP for best modern compression
- Crop before resizing for better results

### For PDFs
- Make PDFs searchable with OCR before archiving
- Compress before sharing to reduce file size
- Protect sensitive PDFs with passwords
- Use "Organize" to reorder or remove pages

### For Security
- Always remove EXIF data from photos
- Protect PDFs with passwords before sharing
- Use watermarks for confidential documents
- Keep personal files in encrypted storage
